# Vyshyvanka Vibes

Адаптивний сайт українського бренду вишиванок. Стек: HTML, CSS, JavaScript і
Vite.

## Поточний стан

Виконано етапи 1–3: основа проєкту, адаптивний Header, мобільне меню й Hero. На
десктопі працюють навігація й телефон; на планшеті видно соцмережі та кнопку
меню, на телефоні — логотип і кнопку меню. Hero містить заголовок, кнопку Order,
дві фотографії та позначку ручної роботи на більших екранах. Інші секції ще
містять каркас із заголовками. Це ще не завершена верстка макета.

Меню закривається кнопкою, Escape, натисканням на затемнення або вибором секції.
Фокус утримується всередині відкритого меню, фон не прокручується; після
закриття відновлюється позиція сторінки. Соцмережі поки є неактивними заглушками
без зовнішніх адрес, як передбачає ТЗ.

Header зафіксований угорі: контент прокручується під його непрозорим фоном.
Якірні переходи враховують висоту Header, щоб він не закривав заголовки.
Активний розділ позначений жовтим кольором і підкресленням у десктопній
навігації та підкресленням у мобільному меню. Під час прокручування активним
стає останній розділ, початок якого перетнув лінію на 24 px нижче Header. При
натисканні пріоритет має вибраний розділ до наступного ручного прокручування; це
також працює, коли кілька коротких секцій видно одночасно.

[Макет Figma](https://www.figma.com/design/Qr6njfbGZKNRb3WzRfHOKV/?node-id=31-23).
Основний фрейм — правий `Desktop_1440` (`31:23`).
[Послідовність етапів і домовленості](./docs/IMPLEMENTATION_PLAN.md).

## Локальна робота

### Зміна фотографій

У Hero фото правого фрейму змінюється на фото лівого кожні 5 секунд і назад.
Перетікання триває 800 ms та не змінює розміру блоку. Напівпрозора кнопка з
двома рисками (пауза) або трикутником (відновлення) має прозорий фон і керує
автоматичною зміною; наведення й фокус також ставлять її на тимчасову паузу.
Перемикання зупиняється поза екраном і в прихованій вкладці. За
`prefers-reduced-motion: reduce` автоматична зміна вимкнена.

`src/js/photo-rotator.js` і `src/css/photo-rotator.css` — спільний механізм для
наступних секцій. Фото завантажуються та декодуються до початку перемикання;
якщо друге фото не завантажилося, залишається доступне зображення.

У `src/img/hero/` збережено WebP для телефона, планшета й десктопа у ×1/×2.
Джерела та розміри описані в [переліку зображень](./docs/ASSETS.md).

### Команди

Потрібна LTS-версія Node.js. Після клонування або зміни залежностей:

```sh
npm ci
npm run dev
```

Відкрий локальну адресу, яку виведе Vite (зазвичай http://localhost:5173/).

```sh
npm run format        # Відформатувати вихідний код
npm run format:check  # Перевірити форматування
npm run build         # Зібрати сайт у dist/
npm run preview       # Переглянути production-збірку
```

Для preview відкрий надруковану Vite адресу з префіксом `/Vyshyvanka-Vibes/`.
Залежності фіксуються в `package-lock.json`; згенерований `dist/` не комітиться.

## Структура

- `src/index.html` — точка входу, метадані та підключення partials.
- `src/partials/` — семантичні блоки сторінки.
- `src/css/styles.css` — підключення нормалізації, шрифту й стилів проєкту.
- `src/css/tokens.css` — кольори, відступи й параметри контейнерів.
- `src/css/reset.css`, `base.css`, `container.css`, `layout.css` — базові стилі.
- `src/img/` — зображення; `logo.svg` експортований із Figma без змін.
- `src/public/favicon.svg` — той самий логотип як фавікон.
- `src/main.js` — точка входу для майбутньої інтерактивності.
- `src/js/mobile-menu.js` — керування меню, фокусом і блокуванням фону.
- `src/img/icons/` — оригінальні SVG-іконки та орнаменти з Figma.

Manrope підключено локально через `@fontsource-variable/manrope`, без звернень
до Google Fonts під час перегляду сайту. Пакет містить латиницю й кирилицю та
використовує ліцензію OFL-1.1. Нормалізація — `modern-normalize`.

Контейнери: гумова ширина до 375 px, далі контрольні розміри 768, 1280 і 1440
px. Бічні відступи відповідно: 20, 32, 50 і 100 px. Мінімальна перевірювана
ширина — 320 px. Приховування горизонтального переповнення не використовується
як спосіб виправлення верстки.

## Публікація

Наявний workflow `.github/workflows/deploy.yml` запускається після push у `main`
і публікує `dist/` у `gh-pages`. Команда збірки використовує
`--base=/Vyshyvanka-Vibes/`. У GitHub Pages джерелом має бути гілка `gh-pages`,
папка `/ (root)`; workflow потрібен дозвіл на запис вмісту репозиторію.

Після кожного завершеного етапу власник самостійно перевіряє, комітить і
відправляє зміни. Наступний етап починається лише після його прохання
продовжити.
